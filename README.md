# course_work_object-oriented programming
Курсовая работа по теме "Объектно-ориентированное программирование"
## О проекте
Проект сделан в рамках курсовой работы по классам и их созданию с использованием Python-языка для закрепления знаний
## По установке:
  * Для PyCharm:
    1. клонировать репозиторий, введя в терминале git clone 
    2. установить зависимости через активированное виртуальное окружение: poetry install
  * Для GitHub:
    1. на странице проекта на кнопке <> Code открыть выпадающий список
    2. выбрать download zip или клонировать через ссылку https или ssh
## По применению проекта:
1. открыть модуль main через pycharm
2. сделать пробег у current file/комбинацией shift + f10/командой python src\main в терминале
## Дополнительно
В функционал проекта входит:
1. базовые классы содержат общие методы для классов и подклассов
2. Vacancies - основной набор функций
3. класс HeadHunterAPI - класс, подключающийся к платформе headhunter и получающая вакансии
4. класс JSONSaver - класс для сохранения в файл и удаления из него вакансий по определенному критерию (пока в сырой)
5. модуль utils - дополняет основную функциональность фильтрациями, сортировкой и ограничением вывода (сколько желает вывести пользоваетль)
6. main, будучи пусковым модулем, запускает код основного интерфейса взаимодействия с пользователем
